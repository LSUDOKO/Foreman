# Foreman

AI outcome agent: phones a clinic's no-shows, rebooks them in the real Cal.com calendar, and is paid only per proven rebooking. Hires phone and proof-oracle agents over x402 on Kite; reasoning by SERV.

Package manager: bun.

## Commands

- test: `bun test`
- typecheck: `bun typecheck`

## Layout

- `apps/`
- `contracts/`
- `demo/`
- `docs/`
- `packages/`
- `scripts/`
- `services/`
- `video/`

## Rules

- Run `bun test` before you say a change is done.
- Never commit secrets or `.env` files.
